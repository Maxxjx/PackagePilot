# 🖥️ Terminal Install Command Builder

A lightweight, modern, and responsive web application that helps users generate a one-line terminal command to install a curated list of essential apps and tools based on their operating system. Built with a minimalist black-themed UI and a vibrant orange accent.

---

## 🚀 Features

- ✅ **Cross-platform Support**: Choose from Windows, macOS, or Linux.
- 📦 **Curated App Lists**: Recommended apps tailored to each OS.
- 🎨 **Modern UI**: Minimalist design with dark mode and orange accents.
- 🧠 **Live Command Generator**: Automatically updates the terminal install command based on selected apps.
- 📋 **Copy to Clipboard**: One-click command copy functionality.
- 🔍 **Search & Filter**: Easily find and select apps.
- 📱 **Responsive Design**: Fully optimized for mobile and desktop use.

## ⚙️ How It Works

1. **Select OS**: Click the OS button (Windows, macOS, or Linux).
2. **Choose Apps**: Check/uncheck apps you want to install.
3. **Generate Command**: Watch the live terminal command preview update.
4. **Copy**: Click the "Copy Command" button to copy it to your clipboard.
5. **Paste in Terminal**: Run the command in your terminal. Done!

Example (Linux):
```bash
sudo apt install firefox code vlc nodejs
```
